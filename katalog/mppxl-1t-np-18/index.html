Описание

Телефонная розетка серии Xelent предназначена для подключения телефонного кабеля и организации проводной связи.

Выполнена из металла, устанавливается в стандартную монтажную коробку типа 86. Рамка приобретается отдельно.

Межосевое расстояние для многопостовых конструкций - 71 мм.

Функции

  • Подключение телефонного кабеля
  • Надёжная работа в составе проводных систем связи
  • Интеграция в общий дизайн серии Xelent
  • Совместимость со стандартной монтажной коробкой типа 86
