Описание

Термостат серии Инкслаб — стильное и функциональное устройство для управления климатом в современном «умном доме». Изготовленный из алюминиевого сплава.

Основной элемент управления — поворотная клавиша Knob с сенсорным экраном, дополненная функциональными кнопками. Такое решение обеспечивает удобное и интуитивное управление кондиционером, системой приточного воздуха и подогревом пола.

Термостат оснащен датчиками температуры, датчик влажности, приближения.

Это позволяет автоматически адаптировать работу климатической системы под реальные условия в помещении.

Пользователь может настроить цвет и яркость светового индикатора кнопок в HDL Studio, а также выбрать вариант подсветки клавиш и лазерной гравировки иконок для индивидуального оформления.

Устройство работает через шинный соединитель MPFPIT-1P-BP.18.

Функции

  • ■ Встроенный датчик температуры и влажности: поддерживает отправку локальных значений температуры и влажности на шину, которые используются для ввода условий сцены и автоматического управления.
  • ■ Встроенный датчик приближения для обнаружения движения человека. Как только датчик обнаруживает движение человека поблизости, сенсорный экран автоматически включается.
  • ■ Пользовательский цвет и яркость светового индикатора кнопки, настраиваемые с помощью HDL Studio.
  • ■ Настраиваемая яркость светового кольца ручки, настраиваемая с помощью HDL Studio.
  • ■ Отдельные страницы для кондиционирования воздуха, подогрева пола и подачи свежего воздуха, каждая из которых управляет только одним устройством.
  • ■ Функция управления на панели: выбор устройства; переключатель/режим /температура / скорость ветра для кондиционирования воздуха; переключатель/температура / режим для подогрева пола; переключатель/ скорость/режим для подачи свежего воздуха.
  • ■ Функция блокировки/ разблокировки кнопок.
  • ■ Поддержка онлайн-обновления HDL Buspro.
