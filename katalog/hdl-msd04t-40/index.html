Описание

Электронный блок HDL-MSD04T.40 – 4-х контактный модуль с каналами сухих контактов и выходами для управления LCD освещением. Первые имеют защиту от искажений, а вторые обеспечивают функцию регулятора мощности. Функционал данного модуля обеспечивает несколько режимов работы:

многофункционального переключателя;

управление каналами, GPRS контроль;

двусторонняя регулировка яркости;

определение состояния сухих контактов;

защита от несанкционированного доступа (при использовании с модулем безопасности).

Также модель MSD04T.40 поддерживает работу температурных датчиков, функцию программирования и онлайн обновления. Светодиодный индикатор на корпусе дублирует режимы работы электронного модуля.

Функции

  • ■ 4-канальный вход сухих контактов с возможностью детекции температур.
  • ■ Поддерживает датчики температур
  • ■ Подключение LED индикаторов
  • ■ Варианты входов: Mechanical switch, Single on, Single off, Single on/off, Combination on, Combination off, Combination on/off, Multifunction, Parallel switch, Temperature sensor.
  • ■ Варианты переключения: Switch mode, Dimmable two-way, dimmable increase, dimmable reduced.
  • ■ Функции клавиш: Scene, Sequence, Universal Switch, Single channel lighting control, Broadcast Scene, Broadcast channel, Curtain Control, Panel Control, GPRS control, Security Module, TT player etc.
  • ■ Функция безопасности, используется с модулем безопасности.
  • ■ Онлайн обновления через ПО HDL Buspro
