Описание

48-канальный DMX контроллер с протоколом DMX1990. Создан для управления RGB LED лентами, RGB лампами и другими DMX устройствами.

Функции

  • ■ 48 каналов, до 48 раздельных зон.
  • ■ 0-99 сцен для каждой зоны, время каждой сцены до 60 минут.
  • ■ Всего 99 последовательностей. 4 режима для каждой последовательности: вперед, назад, вперед и назад, случайно.
  • ■ DMX512 (1990 версия).
  • ■ Поддержка протокола Art net/HDL Net DMX.
  • ■ Низкий, Высокий и Максимальный пороги доступны для каждого канала.
  • ■ Светозащита каждого канала (0-25 секунд).
  • ■ Устройство поддерживает функцию color picker.
  • ■ Задержка включения каждого канала (0-60 минут).
  • ■ Шлюз между HDL Buspro и Ethernet.
