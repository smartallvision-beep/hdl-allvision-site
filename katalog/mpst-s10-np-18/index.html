Описание

Розетка серии Tile 2.1 типа J соответствует швейцарскому стандарту и используется для подключения высоковольтных устройств. Обеспечивает выход AC 250V~, выполнена из прочного пластика и гармонично сочетается с другими модулями серии Tile 2.1. Устанавливается в стандартную монтажную коробку.

Рамка приобретается отдельно.

Функции

  • Поддерживает AC 250V~ выход.
  • Может использоваться для высоковольтных устройств.
  • Совместимость с вилками стандарта J (Швейцария).
