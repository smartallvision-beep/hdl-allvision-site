Описание

Европейская розетка серии Экселент с влагозащитной крышкой предназначена для подачи питания на соответствующее электрическое оборудование.

Напряжение: 250V AC,10А. Подходит для любых типов вилок. Сделана из пластика в двух цветах: белый (слоновая кость), темно-серый.

Межосевое расстояние для многопостовых конструкций - 71 мм.
