Описание

Значки и текст каждой кнопки можно добавить с помощью лазерной гравировки. Благодаря встроенной RGB подсветке для каждой кнопки уровень цвета и яркости может быть установлен с помощью ПО для настройки HDL Buspro или вручную установлен на панели. Панели поддерживают управление освещением, шторами, сценами, музыкой и т. д. Межосевое расстояние для многопостовых конструкций - 86 мм.

Функции

  • ■ Встроенный датчик температyры.
  • ■ Лазерная гравировка на клавишах (доп. опция).
  • ■ Настройка яркости и цвета с помощью софта HDL и вручную.
  • ■ Типы команд: сценарий, последовательность, UV Switch управление каналом, передача состояния канала, управление панелью, команды модуля безопасности, музыка и т. д.
  • ■ Блокировка, взаимоисключение.
  • ■ Обновление из софта.
