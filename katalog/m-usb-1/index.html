Описание

HDL-M/USB.1 в системе домашней автоматизации отвечает за подключение электронных устройств к шине KNX. Модуль USB KNX интерфейса обеспечивает дуплексный (двунаправленный) канал для обмена информацией. Подключение ПК осуществляется через порт USB, а связь поддерживается с помощью стандартного разъема KNX/EIB.

Функциональными особенностями KNX USB интерфейс являются:

отсутствие гальванической связи между шиной KNX и портом USB

возможность настройки IP-адресации всех подключенных устройств

установка, диагностика, введение в эксплуатацию и т.д.

Помимо коннекторов на внешней панели модуля расположены два LED индикатора, один из которых показывают статус подключения, а другой передачу трафика.

Функции

  • M/USB.1 это гальванически изолированный интерфейс KNX-USB двунаправленного доступа к шине через USB, для: введения в эксплуатацию, адресации, установки параметров, визуализации, операций с протоколом, диагностики устройств
  • С помощью интерфейса KNX-USB можно настроить адресацию всех устройств подключенных к шине. Протокол подключения для соединения ПК －USB и KNX BUS TP1.
  • Соединение KNX и ПК стандартным ПО ETS, EITT и другим ПО с драйвером FALCON
