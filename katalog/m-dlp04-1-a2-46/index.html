Описание

Встроенный датчик температуры. Поддержка 147 языков, Раздельное нажатие кнопок влево/вправо. Графика в формате BMP с привязкой к статусу кнопок. Доступны 6 страниц: 3 страницы для управления освещением и нагрузками, страница для управления кондиционером, страница для управления отоплением, страница для управления теплым полом.

Стандартные цвета: Белое стекло.

Доплату за другой цвет уточним при заказе.

Функции

  • Пользователь может менять иконки страниц 1,2,3 с помощью ПО HDL KNX
  • Яркость LCD и LED индикаторов можно настроить через ПО ETS.
  • Поддержка большого числа данных и функций, включая переключатели, диммирование, управление жалюзи, гибкое управление, сцена, последовательность, процентное управление, пороговое управление, комбинированное управление, строка (14 байт), HVAC, аудио, теплый пол, ИК для кондиционера, блокировка кнопок, триггер кнопок, показ температуры, показ времени, удаленный триггер.
  • Для перехода в режим программирования удерживайте первую и последнюю кнопки 2 секунды. Индикатор начнет моргать.
  • Можно настроить звук кнопок.
  • Кнопки можно заблокировать через KNX/ EIB.
