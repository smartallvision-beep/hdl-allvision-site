Описание

51-канальный модуль входа и выхода сухих контактов.

Функции

  • ■ 51 — канал входов и выходов сухих контактов.
  • ■ Варианты входов: Mechanical switch, Single on, Single off, Single on/off, Combination on, Combination off, Combination on/off, Multifunction, Parallel switch, Temperature sensor.
  • ■ Варианты переключения: Switch mode, Dimmable two-way, dimmable increase, dimmable reduced.
  • ■ Функции клавиш: Scene, Sequence, Universal Switch, Single channel lighting control, Broadcast Scene, Broadcast channel, Curtain Control, Panel Control, GPRS control, Security Module, TT player etc.
  • ■ Функция безопасности, используется с модулем безопасности.
  • ■ Онлайн обновления через ПО HDL Buspro.
